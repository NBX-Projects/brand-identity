# NBX Projects — identidade visual

Este repositório reúne os arquivos-mestre, orientações e materiais usados para apresentar a identidade visual da NBX Projects.

> **Ideia da marca:** software feito com clareza e cuidado, representado por um macaco simpático de formas arredondadas e simples.

## Conteúdo

- [`assets/logos/`](assets/logos/) — logos vetoriais, versões monocromáticas e arquivos para ícone.
- [`assets/patterns/`](assets/patterns/) — grafismos auxiliares derivados da curva da cauda.
- [`assets/github/`](assets/github/) — cabeçalho e README usados no perfil público da organização.
- [`docs/guia-identidade.html`](docs/guia-identidade.html) — guia de aplicação da marca.
- [`docs/visao-geral.html`](docs/visao-geral.html) — prancha com exemplos de uso.

## Paleta

| Cor | HEX | Uso |
| --- | --- | --- |
| Grafite macio | `#302B28` | Cor principal, texto e silhueta |
| Casca | `#57483F` | Apoio e contraste |
| Aveia | `#E7D9C9` | Rosto, fundos de apoio e padrão |
| Papel | `#F8F4EC` | Fundo claro |
| Argila clara | `#B3A393` | Detalhes secundários |

## Tipografia

- **Logo:** letras convertidas em contornos vetoriais; não depende de uma fonte instalada para aparecer corretamente.
- **Títulos:** Nunito Sans, pesos 700–800. Alternativa: Segoe UI.
- **Texto:** Segoe UI, pesos 400–600. Alternativa: Arial.

## Uso da marca

Use o logo colorido sobre papel, branco ou aveia. Para fundos grafite, aplique a versão reversa. Preserve proporções, cores e espaçamento; mantenha detalhes extras fora do símbolo. O arquivo `logo-simbolo-pequeno.svg` é a opção simplificada para áreas pequenas.

A frase de apoio sugerida é **“Software feito com clareza e cuidado.”** A descrição pública atual do projeto em destaque é uma plataforma de comunicação e colaboração para desenvolvedores e gamers.

## Perfil do GitHub

O arquivo `assets/github/profile-README.md` é a cópia do conteúdo público do perfil da organização. O cabeçalho associado fica em `assets/github/nbx-header.svg`; sua versão ativa também fica no repositório `.github`, dentro de `profile/README.md` e `profile/assets/`.
